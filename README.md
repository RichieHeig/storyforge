# StoryForge

Socle technique MVP pour StoryForge (React + TypeScript + Vite, Tailwind, Supabase).

## Installation

```bash
npm install
```

## Configuration environnement

Copier le fichier d'exemple et renseigner les valeurs Supabase :

```bash
cp .env.example .env
```

Variables requises :

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

## Lancer le projet

```bash
npm run dev
```

## Build production

```bash
npm run build
npm run preview
```

## Lint

```bash
npm run lint
```
